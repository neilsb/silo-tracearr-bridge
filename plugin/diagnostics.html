Connection checks

  • Cannot bind: check that the configured port is free inside Silo.
  • Silo HTTP 401 or 403: check the upstream API key and its permissions. Artwork also needs profile listing and catalog detail access.
  • HTTP 429: Silo is rate limiting requests. Metadata reads are paced and retried; check other consumers if errors persist.
  • No artwork: the item may lack a poster or be unavailable to the API key owner's primary profile.
  • Tracearr cannot connect: publish port 8098 from the Silo container, use its LAN address in Tracearr, and use the separate bridge key.

This page checks the listener from inside Silo. It cannot prove that Tracearr can reach the published port. Keep the listener task enabled at startup and on a 60-second interval for recovery.

Refresh runs an authenticated session check and starts the listener if needed. All counters reset when the plugin process restarts. Artwork failures include missing posters; the most recent failure remains visible after successful requests. No credentials are displayed.
